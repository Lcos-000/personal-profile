# K8s Notes

Kubernetes 学习笔记，整理了 Kubernetes 的核心架构、Pod 生命周期、网络、存储、扩展和运维等内容。

## 文件

- [`K8sNotes.md`](K8sNotes.md)：可在线阅读的 Markdown 笔记。
- [`K8sNotes.pdf`](K8sNotes.pdf)：笔记 PDF 版本。
- [`assets/`](assets/)：笔记中使用的图片资源。

## 内容概览

- Kubernetes 控制面、Node 和系统组件
- Pod 生命周期、Init Container、Hook 与 Probe
- Service、Ingress、DNS 与网络通信
- 存储、调度、配置和常见运维知识

笔记适合有一定 Kubernetes 使用基础的读者；初学者可以结合官方文档或 AI 辅助理解。
